# Spike results

Run against AWS Emulator 1.0.611 (package released 2026-11-25) on Docker, arm64, with signature checks on. The code was throwaway and is not in the repository.

## Serialization: passes
Service Models were converted at run time to the schemas used by the AWS SDK's own protocol classes (`@aws-sdk/core`, `@smithy/core`; 10 MB installed with the other packages the test needed).

- Every List, Describe, Get or Search operation that returns a collection and needs no input: 2,337 operations in 366 services. No request failed to build or send, and no success response failed to parse. 1,417 succeeded, 749 answered 501, 118 answered an error the operation declares, and 53 answered another error.
- 340 of the 366 services returned at least one list.
- Create-and-read-back passed in all seven protocols: restJson1, awsJson1_0, awsJson1_1, awsQuery, ec2Query, restXml, rpcv2Cbor. They covered nested structures, binary values, timestamps, tags, XML bodies, headers, paths with spaces and accents, and streams.
- Three services speak only rpcv2Cbor: EventBridge v2, CloudWatch Omni, Partner Central Revenue Measurement.
- Not tested: event streams, operations that need input beyond those round trips, and the models the Emulator lacks.

## Gateway: passes
A forwarder that leaves requests unchanged, tried with the AWS SDK for JavaScript v3.

- Signatures verify when the original `Host` is kept, and fail when it is rewritten (control). A wrong key is refused through it (control).
- DynamoDB, SQS, and S3 in path style and virtual-host style, buffered and streamed bodies, and a presigned URL all worked and were all seen.
- The Emulator builds returned URLs from `Host`, so an SQS queue URL names the Gateway. It always says `https`, so the Gateway must accept both plain and TLS connections; one port can do both. TLS needs a certificate of the Gateway's own that the caller trusts.
- Not tested: other SDKs, and returned URLs other than SQS queue URLs and presigned S3.

## Idle timer
With `--idle-timeout 30`, an Emulator polled on its health route every 3 seconds stopped at the same time as one left alone. Checking health does not keep it running. Reading resources was not tried.

## Restart and version
- The access key changes on restart.
- The health route answers `ok` and nothing else. The version is printed only by the command line.
- The package was 1.0.611, a week after the reference clone's 1.0.509.

## Verdicts
Missing features do not always answer 501. In the sweep: UnknownService (404) 8 times, InvalidAction naming an unknown action (400) 4 times, AmbiguousService (500) twice. Ordinary refusals such as ValidationError and MissingParameter are often not declared by the operation.
