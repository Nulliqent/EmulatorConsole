Current run

Current run

1 Failures come first and left: a failure is the more urgent of the two reasons for opening the Console.

Current run, no Calls

1 Two equal ways on, because the Gateway is optional.

Current run after a restart

1 The notice is on every page until dismissed, so an empty list is never read as a fault. New keys are the sign of a restart; the Emulator reports no start time.

Explain a failed call

Calls

1 The error as received comes first; nothing the Console concludes goes above it.

2 The Verdict names its evidence and what it cannot tell.

Calls on a large monitor

1 Error and Verdict keep a readable width while the evidence stays open beside them.

2 Pane edges move by pointer or arrow keys.

Call beside an editor

1 The answer fits above the request and response, so most Calls need no scrolling.

2 Back returns to the same row.

Call, Emulator Gap

1 The response status alone supports this Verdict.

2 It says when to stop looking.

Call, Unclear

1 Two possible causes are named and neither is chosen.

2 The next useful evidence is a Call that worked.

Reach any service

Find

1 Services rank above operations; services seen this run rank first in both groups.

Services

1 The code has usually touched what the Developer is looking for; the full list is the fallback.

Service resources

1 One choice per list the model offers; only the chosen one is read.

2 Field names match the SDK, and the page names the operation the details came from.

Ways a list can end

1 Each ending is worded differently and offers its own next step; an empty list never stands in for a failure.

Service with many lists

1 Past seven lists, the choices become a list that can be filtered, between the service and its resources. EC2 has over 150.

Service without a list

1 It opens on Operations because no list can be read without input; Resources stays, and says which input is needed.

Send an operation

Operation form and response

1 Two views of one input, so a form helps with a new call and JSON takes a paste from code.

2 A field that breaks the model is marked and can still be sent: the Emulator’s refusal is sometimes what is being tested.

3 The same Verdict rules apply as to a Call.

Confirm a Destructive Operation

1 It names the operation, the resource and the Region, and asks once. Neither button is the default, so Return alone never deletes; Escape cancels.
